# TaskManager API

Учебный REST API для управления проектами, сотрудниками и задачами.

## Технологии

- Python 3.11+
- FastAPI
- SQLAlchemy 2.x
- Pydantic 2.x
- SQLite

## Возможности

- Создание, просмотр, обновление и удаление проектов, сотрудников и задач.
- Назначение исполнителя и изменение статуса задачи.
- Поиск задач по названию и сотрудников по имени.
- Фильтрация задач по статусу, приоритету, проекту, исполнителю и сроку.
- Пагинация списков задач и сотрудников.
- Проверка уникальности названия проекта и email сотрудника.
- Запрет удаления проектов и сотрудников, у которых есть задачи.

## Запуск в Windows PowerShell

Выполните команды из корневой папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Для запуска нужен установленный Python 3.11 или новее. База данных
`taskmanager.db` и таблицы создаются автоматически при запуске приложения.

Интерактивная документация Swagger UI: http://127.0.0.1:8000/docs

Веб-интерфейс TaskManager: http://127.0.0.1:8000/

Интерфейс использует HTML, CSS и JavaScript без сборки. Доступны тёмная и
светлая темы, английский и русский языки, обзор проектов, задачи и команда.
Язык и тема сохраняются в браузере; токен входа хранится в рамках вкладки.
Администраторы могут создавать и удалять записи, управлять проектами и
участниками. Вошедшие пользователи могут просматривать данные, изменять
задачи и их статусы в соответствии с текущими разрешениями API.
Для создания первого администратора выполните `python createsuperuser.py`.

Для остановки сервера нажмите `Ctrl+C`.

## Структура проекта

- `app/main.py` — создание приложения и подключение роутеров.
- `app/database.py` — подключение к базе данных и управление сессиями.
- `app/models.py` — модели проектов, сотрудников и задач.
- `app/schemas.py` — валидация входных данных и схемы ответов.
- `app/crud.py` — операции с базой данных.
- `app/routers/` — обработчики HTTP-запросов.

Основные разделы API: `/projects/`, `/employees/`, `/tasks/`.

## Аутентификация

При настройке на другом компьютере скопируйте `.env.example` в `.env` и замените
`JWT_SECRET_KEY` собственным случайным секретом. Локальный `.env` уже создан.
Не добавляйте его в Git.

1. Зарегистрируйтесь через `POST /auth/register` (JSON: `username`, `password`).
2. В Swagger нажмите **Authorize** и введите логин и пароль.
3. После входа доступны защищённые маршруты проектов, сотрудников и задач.

`POST /auth/login` принимает поля формы, а не JSON, и возвращает JWT.
`GET /users/me` возвращает текущего пользователя.
`GET /admin/users` доступен только пользователю с `is_admin=True`.
При регистрации пользователи получают `is_admin=False`; публичного назначения
администраторов нет. Токен по умолчанию действует 30 минут.
